How to Connect OpenClaw to This Portal

This web app supports URL Query Automation and Direct SerpApi JSON Injection. OpenClaw can automatically search real flights, fill in passenger details, hide all fares, and open the ready PDF!

Copy & Paste This Prompt to OpenClaw: 
Amar jonno real flight search kore PDF E-Ticket (Without Fare) bananor jonno tumi SerpApi Google Flights use korbe:

1. SerpApi Endpoint:
https://serpapi.com/search.json?engine=google_flights&departure_id={FROM}&arrival_id={TO}&outbound_date={YYYY-MM-DD}&type=2&api_key=YOUR_SERPAPI_KEY

2. IMPORTANT RULE: Kokhono kono ticket price ba fare dekhabena (100% Hide Fare).

3. PDF Ticket Generator URL Parameters:
Tumi sorasori amar web app-e nicher URL format-e parameter pass kore browser-e open korbe ba link dibe:
?from=DAC&to=RUH&date=2026-11-15&pax=MR+RAHIM+UDDIN&passport=A12345678&pnr=K8M9P2&auto=1

Supported URL Parameters for OpenClaw:

  • from=DAC & to=RUH (3-letter IATA airport codes)
  • date=2026-11-15 & return_date=2026-11-25 (optional)
  • pax=MR+SHAWON+AHMED (Passenger full name)
  • passport=B00192834 (Passport number)
  • pnr=X7M9K2 (Custom PNR code)
  • agency=EASY+TRAVELS (Agency name)
  • api_key=YOUR_SERPAPI_KEY (Auto-saves key & runs live search)
  • auto=1 (Automatically jumps to PDF preview after loading flight)
